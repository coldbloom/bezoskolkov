# Без Осколков

Сайт на Next.js 16 с готовым HTML для всех страниц. Сборка экспортируется в `out/` и не требует Node.js на хостинге.

## Сборка и проверка

```bash
yarn install --immutable
yarn build
yarn lint
yarn check:export
```

Перед сборкой задайте `NEXT_PUBLIC_SITE_URL` и телефоны из `.env.example`. Канонические адреса, sitemap, robots.txt и номера в HTML фиксируются **во время сборки**; после изменения переменных сайт нужно пересобрать.

Размещайте **содержимое `out/`** в корне сайта. Хостинг должен отдавать `index.html` для URL с завершающим `/`, перенаправлять адреса без завершающего `/` на канонический URL и возвращать статус HTTP 404 вместе с `404.html` для несуществующих страниц. Проверьте MIME-типы для `.webp`, `.png`, `.xml` и `.txt`. Для ускорения включите Brotli или gzip и длительное кеширование файлов в `/_next/static/`. Не загружайте на хостинг `node_modules`, `.next` и `assets/originals`.

Оригиналы двух больших иллюстраций находятся в `assets/originals/`; оптимизированные варианты шириной 768, 1280 и 1536 пикселей — в `public/`. При замене иллюстраций обновите все три размера WebP и проверьте результат командой `yarn check:export`.

Форма расчёта пока не отправляет данные: для реальных заявок нужна интеграция с CRM, почтой или другим сервисом. Региональные страницы технически доступны для индексации, но их шаблонный контент необходимо дополнять настоящими локальными сведениями и примерами работ, если цель — сильное ранжирование по региональным запросам.
